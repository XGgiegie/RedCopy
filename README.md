# 薯薯小抄

🚀 一款专注于小红书内容提取与 AI 深度解析的浏览器扩展。支持一键提取笔记图文、Markdown 导出，并结合 AI 提供笔记结构剖析与爆款逻辑拆解。

---

## ✨ 核心功能

- **内容提取**：一键抓取笔记标题、正文、标签、互动数据及图片。
- **便捷导出**：支持复制为标准 Markdown 格式、纯文本正文，或直接提取图片链接。
- **媒体下载**：支持单张或批量下载无水印原图；支持视频笔记文案的 AI 文本解析。
- **AI 深度解析 (BYOK)**：采用“自带 Key”模式（需用户自行配置 DeepSeek API Key），一键分析笔记结构与传播逻辑。
- **内容仿写**：基于 AI 解析结果，输入推广主题即可生成结构相似的可编辑笔记。

## 🛠️ 安装与使用

### 方式一：应用商店安装（推荐）
- 已上架 Chrome Web Store / Microsoft Edge Add-ons（视审核进度提供）。直接搜索“薯薯小抄”进行安装。

### 方式二：开发者模式本地加载
1. 下载本项目最新源码或发行包（Zip）。
2. 在浏览器地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）打开扩展程序页面。
3. 开启右上角的**开发者模式**。
4. 点击“加载已解压的扩展程序”，选择项目的 `dist` 目录即可使用。

## 💻 本地开发

本项目基于 Vue 3 + TypeScript + Vite 构建。

```bash
# 安装依赖
npm install

# 启动开发服务器 (支持热更新)
npm run dev

# 构建打包生成 dist 目录
npm run build

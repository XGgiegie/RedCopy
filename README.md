# 薯薯小抄 RedCopy

薯薯小抄是一款面向小红书内容整理与 AI 辅助创作的浏览器扩展。它可以在用户主动触发时提取公开可见的笔记内容，整理为可复制、可导出、可下载的素材，并在用户自备 API Key 的前提下提供 AI 分析、类似笔记生成和配图创作能力。

扩展适用于 Chrome、Microsoft Edge 等 Chromium 内核浏览器。

## 核心能力

- 笔记提取：提取标题、正文、标签、互动数据、图片列表等公开可见内容。
- 内容导出：复制 Markdown、复制正文、复制图片链接，并支持汇总导出。
- 图片下载：支持单张或批量下载笔记图片。
- AI 分析：使用用户自备 API Key 分析笔记结构、内容亮点与传播逻辑。
- 类似笔记：基于分析结果生成可编辑的标题、正文和标签。
- AI 配图：支持文生图、图生图、上传配图与配图历史管理。
- 本地任务：提取、分析、创作结果按任务保存在浏览器本机。

## 安装使用

### 商店安装

在 Chrome Web Store 或 Microsoft Edge Add-ons 搜索「薯薯小抄」，按浏览器提示添加扩展。

### 本地开发包安装

1. 获取项目源码或发布包。
2. 执行构建，生成 `dist` 目录。
3. 打开 `chrome://extensions/`，Edge 使用 `edge://extensions/`。
4. 开启「开发者模式」。
5. 点击「加载已解压的扩展程序」，选择项目的 `dist` 目录。

## 本地开发

```bash
npm install
npm run dev
```

构建扩展：

```bash
npm run build
```

生成可发布压缩包：

```bash
npm run package
```

常用脚本：

- `npm run dev`：启动 Vite 开发服务。
- `npm run dev:watch`：监听构建，适合配合浏览器扩展调试。
- `npm run build`：类型检查并构建 `dist`。
- `npm run icons`：生成扩展图标资源。
- `npm run package`：生成图标、构建扩展并打包。

## 推荐流程

1. 打开一篇小红书笔记详情页。
2. 点击浏览器工具栏中的薯薯小抄图标，打开右侧栏。
3. 点击「提取当前笔记」。
4. 在任务详情中查看笔记内容、复制文本或下载图片。
5. 如需 AI 能力，先在设置页保存 API Key。
6. 执行 AI 分析，查看结构拆解与创作建议。
7. 生成类似笔记并编辑标题、正文、标签。
8. 生成或上传配图，最后复制内容或导出 Markdown。

## 隐私原则

- 扩展不运营开发者后端服务器。
- API Key、任务数据和草稿默认保存在本机 `chrome.storage.local`。
- 只有用户主动点击提取、分析或生成时，扩展才读取页面或发起网络请求。
- AI 请求由用户浏览器直连用户配置的服务商 API。

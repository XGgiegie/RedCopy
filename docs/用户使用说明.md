薯薯小抄 · 用户使用说明

小红书笔记提取、AI 分析与仿写助手。适用于 Chrome、Edge 等 Chromium 内核浏览器。

交流反馈：QQ 1653444718 · 群 870774371


一、安装

【商店安装】上架后在 Chrome 网上应用店搜索「薯薯小抄」，点击添加即可。

【手动安装】适合内测或开发版：
1. 解压发布包（如 薯薯小抄-v1.1.0.zip），或执行 npm run package 后使用 dist 文件夹
2. 打开 chrome://extensions/（Edge 为 edge://extensions/）
3. 开启开发者模式
4. 加载已解压的扩展程序，选择 dist 文件夹


二、首次配置

1. 打开小红书页面，点击工具栏「薯薯小抄」图标，右侧会打开侧栏
2. 点击右上角齿轮进入设置
3. 填写火山方舟 ARK API Key（在火山引擎控制台申请：https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey）
4. Key 只保存在本机，不会上传到开发者服务器

说明：提取、复制、下载笔记图片不需要 Key。AI 分析、生成类似笔记、AI 配图生成需要 Key，费用由用户在火山方舟账户自行承担。

分析模型（Lite / Mini / Pro）在任务详情页顶部切换，分析、生文、识图共用同一个 Key。


三、推荐使用流程

1. 打开一篇小红书笔记详情页
2. 侧栏首页点击「提取当前笔记」，笔记会作为一条任务保存到历史列表
3. 点进该任务，在「笔记」页可预览原文、复制或下载图片；有配图时可勾选参与 AI 识图
4. 点击「AI 分析笔记」，完成后在「AI 分析」页查看拆解结果
5. 点击「生成类似笔记」，可填写想推广的主题或卖点（选填）
6. 在「类似笔记」页编辑标题、正文、标签；使用配图创作区生成或上传配图
7. 复制内容或一键导出 Markdown，点击「打开发布页」跳转小红书创作者中心自行发布

多条笔记互不影响：每条提取都是独立任务，切换任务不会串分析或生成结果。离开任务页后，进行中的分析/生成会在后台继续，列表上会显示进度。


四、功能说明

【任务列表】
首页展示历史任务，可见提取 / 分析 / 生成进度。支持删除任务；进行中的任务暂不可删。
「一键导出全部笔记（Markdown）」可将所有任务汇总下载为一个 .md 文件。

【提取当前笔记】
须在小红书笔记详情页使用（URL 含 /explore/ 或 /discovery/item/）。
图文笔记：提取标题、正文、标签、互动数据、图片列表。
视频笔记：可提取文案，图片多为封面；不做视频解析。

【任务详情 · 笔记】
横向滑动查看图片，支持复制 Markdown / 正文 / 图片链接，支持单张或全部下载。
若笔记有图，可勾选要参与 AI 识图的图片（至少选一张才能带图分析）。

【任务详情 · AI 分析】
需先完成提取。输出爆款拆解、标题与结构分析、创作建议等，可复制纯文本或 Markdown。

【任务详情 · 类似笔记】
需先完成 AI 分析。生成后可编辑，修改会自动保存。
配图创作：AI 会为每条配图生成可直接文生图的提示词；可选尺寸，可上传/拖拽参考图做图生图；支持上传自己的配图；生成结果进入配图历史，可预览放大、复制 Markdown、下载。历史离开页面仍会保留。

【打开发布页】
跳转小红书创作者中心图文发布页，标题正文需自行粘贴上传（扩展不自动填入发布框）。


五、常见问题

侧栏打不开：确认浏览器较新，在扩展管理页重新加载扩展。

提取按钮灰色：请先打开小红书笔记详情页，而非首页或搜索结果。

AI 失败：检查 ARK API Key、火山方舟余额与模型权限；侧栏右键检查 → Console 可查看 [RedCopy] 日志。

配图生成失败：确认 Key 有效；参考图须为图片文件；豆包返回的图片链接有时效，建议及时下载。

图片下载失败：确认浏览器允许下载，扩展已重新加载。

切换任务后结果错乱：v1.1 起每条笔记独立任务存储，若仍异常请重新提取为新任务。


六、隐私与数据

扩展不收集用户个人信息。
API Key 与任务数据（笔记、分析、草稿、配图历史）保存在本机 chrome.storage.local。
仅在用户主动点击提取时读取当前页面内容。
AI 与配图请求由本机直接发往火山方舟（ark.cn-beijing.volces.com）。

详见项目根目录 PRIVACY.md。

# 薯薯小抄 用户使用说明

薯薯小抄是一个小红书笔记提取与 AI 创作助手。它帮助你把公开可见的小红书笔记整理成本地任务，并进一步完成分析、仿写和配图创作。

适用浏览器：Chrome、Microsoft Edge，以及其他支持 Chromium 扩展的浏览器。

## 1. 可以做什么

不配置 API Key 也可以使用：

- 提取当前笔记的标题、正文、标签、互动数据和图片。
- 复制 Markdown。
- 复制纯文本正文。
- 复制图片链接。
- 下载单张或全部图片。
- 导出历史笔记 Markdown。

配置 API Key 后可以使用：

- AI 分析笔记结构、选题角度和传播逻辑。
- 生成类似笔记草稿。
- 根据提示词生成配图。
- 上传、拖拽或粘贴参考图进行图生图。
- 保存并复用配图历史。

## 2. 安装方式

### 商店安装

在 Chrome 或 Edge 扩展商店搜索「薯薯小抄」，点击添加到浏览器。

### 手动安装

1. 解压发布包，或在项目中执行 `npm run package`。
2. 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择构建产物中的 `dist` 文件夹。

## 3. 首次使用

1. 打开任意小红书笔记详情页。
2. 点击浏览器工具栏中的扩展图标。
3. 在右侧栏中点击「提取当前笔记」。
4. 等待提取完成后，进入任务详情查看内容。

注意：提取功能需要在笔记详情页使用。首页、搜索结果页、个人主页可能无法提取。

## 4. 配置 AI

AI 功能采用 BYOK 模式，也就是用户自备 API Key。

1. 打开扩展右侧栏。
2. 点击设置入口。
3. 填写 API Key 并保存。
4. 回到任务详情页，执行 AI 分析或内容生成。

API Key 保存在浏览器本机，不上传开发者服务器。AI 服务费用由你的服务商账户承担。

## 5. 推荐工作流

1. 进入小红书笔记详情页。
2. 点击「提取当前笔记」。
3. 在「笔记」页检查标题、正文、标签和图片。
4. 复制 Markdown、下载图片，或继续使用 AI。
5. 点击「AI 分析」，查看结构拆解和创作建议。
6. 点击「生成类似笔记」，按需要填写推广主题或创作方向。
7. 在类似笔记页编辑标题、正文、标签。
8. 在配图区域使用文生图、图生图或上传自有图片。
9. 复制最终内容，或导出 Markdown。
10. 如需发布，打开小红书创作者中心，自行粘贴文本并上传图片。

## 6. 功能说明

### 任务列表

任务列表显示历史提取记录，以及提取、分析、创作进度。你可以进入任务详情继续查看或编辑，也可以删除不再需要的任务。进行中的任务通常不建议删除。

### 提取当前笔记

图文笔记通常可提取：

- 标题
- 正文
- 标签
- 作者公开信息
- 点赞、收藏、评论等公开互动数据
- 图片列表

视频笔记通常可提取文案和封面信息，扩展不会分析视频画面内容。

### 笔记详情

在笔记详情页可以预览内容、横向浏览图片、复制 Markdown、复制正文、复制图片链接，或下载图片。

### AI 分析

AI 分析需要先完成笔记提取，并配置有效 API Key。分析结果可用于理解笔记结构、爆点、表达方式和可复用的创作思路。

### 类似笔记

类似笔记需要先完成 AI 分析。生成结果可以继续编辑，编辑内容会保存到本机任务数据中。

### 配图创作

配图创作支持：

- 文生图：输入提示词生成图片。
- 图生图：上传、拖拽或粘贴参考图，再结合提示词生成图片。
- 自定义上传：直接使用自己的图片作为配图。
- 配图历史：保存历史结果，便于预览、复制 Markdown 或下载。

## 7. 常见问题

### 侧栏打不开

请确认浏览器版本较新，并在扩展管理页重新加载扩展。如果仍然异常，可以重启浏览器。

### 提取按钮不可用

请先打开具体笔记详情页，而不是首页、搜索页或个人主页。

### AI 功能报错

请检查 API Key 是否保存、服务商账户余额是否充足、模型权限是否可用。也可以在扩展侧栏右键选择「检查」，查看 Console 中的 `[RedCopy]` 日志。

### 图片上传没有反应

可以改用拖拽图片或 `Ctrl+V` 粘贴图片。建议使用 JPG、PNG、WebP 等常见格式。

### AI 生成图片链接失效

远程生成图片可能有时效限制。建议生成后及时下载保存到本机。

### 任务数据异常

每条笔记是独立任务。如果某条任务显示异常，可以删除该任务后重新提取。

## 8. 隐私与数据

- 扩展不收集姓名、邮箱、手机号等个人身份信息。
- API Key 和任务数据保存在本机 `chrome.storage.local`。
- 扩展只在用户主动点击相关按钮时读取当前页面内容。
- AI 请求由浏览器直连用户配置的服务商 API。
- 卸载扩展或清除扩展数据后，本机保存的数据会被删除。

完整隐私说明见项目根目录 `PRIVACY.md`。

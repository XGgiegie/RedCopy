# 薯薯小抄 · 用户使用说明

小红书笔记提取与 AI 解析浏览器扩展。支持 Chrome、Edge 等 Chromium 内核浏览器。

## 安装

### 从 Chrome 网上应用店安装（上架后）

在 Chrome 网上应用店搜索「薯薯小抄」，点击「添加至 Chrome」。

### 手动安装（内测 / 开发版）

1. 解压 `薯薯小抄-v1.0.0.zip`，或在本项目执行 `npm run package` 后使用 `dist` 文件夹
2. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）
3. 开启右上角 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择 `dist` 文件夹

---

## 首次配置

1. 打开任意小红书页面，点击浏览器工具栏中的 **薯薯小抄** 图标
2. 侧栏会在浏览器右侧打开
3. 点击右上角 **⚙ 齿轮**，配置 **DeepSeek API Key**
   - 前往 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 自行申请
   - Key 仅保存在本机，不会上传至开发者服务器
4. 选择分析模型后点击 **保存**

> AI 分析、生成类似笔记功能需要 API Key。仅使用提取、复制、下载图片功能时，可不配置 Key。

## 功能说明

### 1. 执行提取

- 在 **小红书笔记详情页** 点击「执行提取」
- 自动读取标题、正文、标签、互动数据、图片
- **图文笔记**：完整提取内容与图片
- **视频笔记**：可提取标题、正文等文案，图片一般为封面；不支持视频解析

### 2. 笔记预览

提取后可切换查看：

| 标签 | 内容 |
|------|------|
| 笔记 | 原文预览 |
| AI 分析 | 分析结果 |
| 类似笔记 | AI 生成稿（可编辑） |

**复制与下载：**

- **复制 Markdown**：整篇笔记 Markdown
- **复制正文**：仅正文纯文本
- **复制图片**：图片 Markdown 链接
- **全部下载 / 单张下载**：保存笔记图片到本地

图片区域为 **横向滑动**，完整显示不裁剪。

### 3. AI 分析

- 需先 **执行提取**，再点击「AI 分析」
- 分析笔记结构、标题钩子、互动逻辑等
- 支持复制纯文本或 Markdown

### 4. 生成类似笔记

- 需先完成 **AI 分析**
- 可在输入框填写 **想卖什么 / 主题或卖点**（选填，留空也能生成）
- 点击「生成类似笔记」，AI 会参考原笔记与分析结果创作新稿
- 生成后可 **直接编辑** 标题、正文、标签、配图建议，修改会自动保存
- 支持 **复制** / **Markdown** 导出

### 5. 重新提取

点击「重新提取笔记」会 **清空** 当前的 AI 分析与类似笔记，避免与新笔记内容错位。

## 常见问题

**侧栏打不开？**  
确认浏览器版本较新，并在 `chrome://extensions` 中重新加载扩展。

**提取按钮灰色？**  
请先打开小红书 **笔记详情页**（URL 含 `/explore/` 或 `/discovery/item/`）。

**AI 分析失败？**  
检查 API Key 是否正确、DeepSeek 账户是否有余额，侧栏 DevTools 控制台可查看错误日志。

**图片下载失败？**  
确认扩展已重新加载，并允许浏览器下载文件。

**设置页保存失败？**  
请在小红书页面打开侧栏，点击 ⚙ 在侧栏内配置 API Key。

## 隐私与数据

- 扩展 **不收集** 用户个人信息
- API Key 仅存于本机 `chrome.storage.local`
- 仅在用户 **主动点击提取** 时读取当前页面内容
- AI 请求由本机直接发往 `api.deepseek.com`

详见 [隐私政策](../PRIVACY.md)。

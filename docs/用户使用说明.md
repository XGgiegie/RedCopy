薯薯小抄 · 用户使用说明

小红书笔记提取与 AI 创作助手，适用于 Chrome、Edge 等 Chromium 内核浏览器。

交流反馈：QQ 1653444718 · 群 870774371

说明：本文档以产品能力为主编写，不绑定具体版本号或 AI 模型名称。界面文案、模型列表、申请入口以扩展内实际展示为准。


一、你能用它做什么

薯薯小抄帮助你在浏览小红书笔记时，把公开可见的内容整理到本机，并可选地借助 AI 完成分析与创作。

不需要 API Key 即可使用：
  提取笔记、复制、下载图片、导出 Markdown

需要自备 API Key 才可使用：
  AI 分析、生成类似笔记、AI 配图等增强能力

核心流程：提取 → 分析 → 创作。每条笔记是独立任务，互不影响；离开页面后，进行中的 AI 操作仍会在后台继续，列表可看到进度。

扩展本体免费；AI 相关费用由你在对应服务商账户自行承担。


二、安装

【商店安装】（推荐）
在 Chrome / Edge 扩展商店搜索「薯薯小抄」，点击添加即可。

【手动安装】（内测或开发包）
1. 解压发布 zip，或执行 npm run package 后使用 dist 目录
2. 打开 chrome://extensions/（Edge 为 edge://extensions/）
3. 开启「开发者模式」
4. 选择「加载已解压的扩展程序」，指向 dist 文件夹

版本号可在浏览器扩展管理页查看。


三、首次使用

1. 打开任意小红书页面，点击工具栏扩展图标，右侧打开侧栏
2. 进入一篇笔记详情页（非首页或搜索结果）
3. 在侧栏首页点击「提取当前笔记」

【可选：配置 AI】
1. 点击侧栏右上角齿轮进入设置
2. 按设置页说明填写 API Key 并保存（Key 仅存本机，不上传开发者服务器）
3. 申请 Key 的链接与当前支持的能力，以设置页展示为准
4. 分析用模型在任务详情页顶部切换；不会配置可联系作者 QQ：1653444718

未配置 Key 时，提取、复制、下载、导出等基础功能仍可正常使用。


四、推荐使用流程

1. 打开小红书笔记详情页，侧栏点击「提取当前笔记」
2. 在历史任务中进入该笔记，在「笔记」页预览原文，可复制或下载图片
3. 需要 AI 时：点击「AI 分析」，在「AI 分析」页查看结果
4. 点击「生成类似笔记」（可填推广主题，选填），在「类似笔记」页编辑标题、正文、标签
5. 在配图创作区生成或上传配图；结果进入配图历史，可预览、复制 Markdown、下载
6. 复制内容或导出 Markdown；需要发布时点击「打开发布页」跳转小红书创作者中心，自行粘贴上传


五、功能说明

【任务列表】（侧栏首页）
  展示历史任务及提取 / 分析 / 创作进度
  支持删除任务（进行中的任务暂不可删）
  「一键导出全部笔记（Markdown）」可汇总下载为一个 .md 文件

【提取当前笔记】
  须在笔记详情页使用（URL 通常含 /explore/ 或 /discovery/item/）
  图文笔记：标题、正文、标签、互动数据、图片列表
  视频笔记：可提取文案，图片多为封面；不做视频内容解析

【任务详情 · 笔记】
  预览与横向浏览图片
  复制 Markdown / 正文 / 图片链接；单张或全部下载
  有配图时可勾选参与 AI 识图（带图分析需至少选一张）

【任务详情 · AI 分析】
  需先完成提取
  输出结构拆解、创作建议等，可复制纯文本或 Markdown

【任务详情 · 类似笔记】
  需先完成 AI 分析
  生成后可编辑，修改会自动保存
  配图创作：提示词文生图；可上传 / 拖拽 / 粘贴参考图做图生图；可上传自己的配图；历史记录会持久保存

【打开发布页】
  跳转小红书创作者图文发布页
  扩展不会自动填入发布框，标题、正文、图片需自行粘贴上传


六、常见问题

问：侧栏打不开
答：确认浏览器较新，在扩展管理页重新加载扩展。

问：提取按钮为灰色
答：请先打开笔记详情页，而非首页、个人页或搜索结果。

问：AI 功能报错或没反应
答：检查设置页 API Key 是否已保存、服务商账户余额与权限是否正常；在侧栏右键「检查」打开 Console，查看 [RedCopy] 日志。

问：配图上传点选无反应
答：侧栏内文件选择框可能受浏览器或其他扩展影响。可改用拖拽或 Ctrl+V 粘贴图片；支持 JPG、PNG、WebP 等常见格式。

问：配图生成失败或链接失效
答：确认 Key 有效；AI 生成的远程图片链接可能有时效，建议及时下载保存到本机。

问：图片下载失败
答：确认浏览器允许下载，并尝试重新加载扩展。

问：任务数据异常
答：每条笔记为独立任务存储。若显示异常，可删除该任务后重新提取。


七、隐私与数据

  扩展不收集姓名、邮箱等个人身份信息
  API Key 与任务数据（笔记、分析、草稿、配图历史）保存在本机 chrome.storage.local
  仅在用户主动点击「提取」时读取当前页面内容
  AI 请求由本机直连用户配置的服务商 API，不经开发者服务器转发

完整说明见项目根目录 PRIVACY.md

# 薯薯小抄 · Chrome 隐私权填报指南

本文档对应 [Chrome 开发者控制台](https://chrome.google.com/webstore/devconsole) 上架时的 **隐私权做法**、**权限说明**、**单一用途** 等表单，可直接复制粘贴。

隐私政策正文见项目根目录：[PRIVACY.md](../PRIVACY.md)（需发布为公开 URL 后填入商店）。

## 四、数据收集类型填报

> 说明：以下指 **开发者是否远程收集并存储** 用户数据。本扩展无开发者服务器，数据主要存于用户本机。

| Chrome 表单数据类型 | 是否收集 | 填报说明（可复制到「用途说明」） |
|---------------------|----------|----------------------------------|
| 个人身份信息（姓名、地址、邮箱、电话等） | **否** | 本扩展不收集任何个人身份信息。 |
| 健康信息 | **否** | 不收集。 |
| 财务与付款信息 | **否** | 不收集；扩展免费，无应用内支付。 |
| 身份验证信息 | **否*** | 用户自行填写的 DeepSeek API Key 仅保存在本机 `chrome.storage.local`，不上传至开发者服务器。 |
| 个人通信 | **否** | 不读取聊天、邮件等通信内容。 |
| 位置信息 | **否** | 不收集 GPS 或精确位置。 |
| 浏览记录 / 上网历史 | **否** | 不记录、不上传用户浏览历史；仅检测当前标签页是否为小红书笔记详情页以启用按钮。 |

```
用户可选填 DeepSeek API Key，仅存储在用户浏览器本地，用于直接向 api.deepseek.com 发起 AI 请求；开发者不接收、不存储该 Key。
```

```
数据仅在用户主动触发提取时读取，保存在本机，用于侧栏展示与导出；除用户自备 Key 调用 DeepSeek 外，不向第三方传输。
```

## 五、权限逐项说明

### 5.1 普通权限

#### `sidePanel`

```
用于在浏览器右侧打开「薯薯小抄」操作侧栏，展示提取结果、AI 分析与生成稿编辑界面。不读取侧栏以外的页面数据。
```

#### `storage`

```
用于在用户浏览器本地保存：DeepSeek API Key（用户自愿配置）、AI 模型选择、上次提取的笔记、上次 AI 分析结果、上次生成的类似笔记草稿。数据不上传至开发者服务器。
```

#### `activeTab`

```
用于在用户点击「执行提取」时，访问当前激活的小红书笔记标签页以读取笔记内容。仅在用户主动操作时生效。
```

#### `scripting`

```
用于向当前小红书笔记页面注入提取脚本，读取笔记标题、正文、标签、图片链接等公开可见内容。仅在用户点击「执行提取」时执行，不后台自动运行。
```

#### `tabs`

```
用于获取当前浏览器标签页的 URL，判断用户是否处于小红书笔记详情页，从而启用或禁用「执行提取」按钮。不读取标签页以外的敏感信息。
```

#### `webNavigation`

```
用于监听当前标签页的 URL 变化（含单页应用路由跳转），实时更新侧栏中的页面状态提示（已就绪 / 非笔记页）。不记录或上传浏览历史。
```

#### `downloads`

```
用于将用户主动选择的笔记图片保存到本地下载文件夹。仅在用户点击「下载」或「全部下载」时触发。
```

### 5.2 主机权限（Host permissions）

#### `*://*.xiaohongshu.com/*`

```
访问用户当前打开的小红书笔记详情页，以便在用户主动点击「执行提取」时读取页面中的笔记文本与元数据。不访问其他网站。
```

#### `*://*.xhscdn.com/*`

```
访问小红书图片 CDN 地址，以便在用户主动下载笔记图片时将图片保存到本地。不用于追踪或分析用户行为。
```

#### `https://api.deepseek.com/*`

```
当用户配置 DeepSeek API Key 并主动使用「AI 分析」或「生成类似笔记」时，由用户浏览器直接向 DeepSeek API 发送笔记文本与用户输入的推广主题。请求不经过开发者服务器；API Key 由用户自备并仅存于本机。
```

## 六、远程代码（Remote code）

**是否使用远程代码：** 否（扩展包内代码固定）

**是否调用远程 Hosted API：** 是（用户主动触发）

```
本扩展不包含动态加载的远程 JavaScript。AI 功能由用户主动触发，浏览器使用用户本机保存的 API Key 向 DeepSeek 官方 API（api.deepseek.com）发送 HTTPS 请求。除 DeepSeek 外，不与开发者或其他第三方 API 通信。
```

## 七、第三方服务与数据传输

| 第三方 | 传输时机 | 传输内容 | 说明 |
|--------|----------|----------|------|
| DeepSeek (`api.deepseek.com`) | 用户点击 AI 分析 / 生成类似笔记 | 笔记标题、正文、标签、互动数据、用户可选填的推广主题、AI 分析结果（生成时） | 用户自备 API Key，费用由用户承担；请参阅 DeepSeek 隐私政策 |
| 小红书 (`xiaohongshu.com`) | 用户点击执行提取 | 无上传；仅本机读取页面 DOM / 页面数据 | 只读，不向小红书额外发送数据 |
| 开发者服务器 | 无 | 无 | 本扩展不与开发者服务器通信 |

## 八、数据保留与删除

```
所有配置与提取/分析/生成结果均保存在用户浏览器 chrome.storage.local 中。
用户可通过以下方式删除数据：
1. 在扩展内重新提取笔记（会清空上次 AI 结果）
2. 在 chrome://extensions 中移除本扩展（清除全部本地数据）
本扩展不提供云端备份，开发者无法远程删除或导出用户数据。
```

## 十二、常见审核追问 · 标准回复

**问：为何需要访问小红书？**

```
扩展核心功能是从用户正在浏览的小红书笔记详情页提取公开可见的标题、正文、标签与图片链接。提取仅在用户点击按钮后执行，不自动批量爬取。
```

**问：为何需要 api.deepseek.com？**

```
AI 分析与生成类似笔记功能使用用户自备的 DeepSeek API Key，由浏览器直接向官方 API 发请求。开发者不托管、不转发用户 Key。
```

**问：是否收集浏览历史？**

```
否。扩展仅检查当前激活标签页 URL 是否为笔记详情页，不记录、不上传历史记录。
```

**问：数据是否用于广告或出售？**

```
否。当前版本免费，无广告，不出售数据，不用于与核心功能无关的目的。
```

## 十三、填报顺序建议

1. 上传 zip 包
2. 填写商品信息（名称、说明、截图）
3. 打开 **隐私权做法** → 粘贴隐私政策 URL
4. 完成 **数据使用认证** 三项确认
5. 按第四节表格逐项填写数据类型
6. 在 **权限** / **隐私** 备注中粘贴第五节说明
7. 填写单一用途（第二节）
8. 提交审核

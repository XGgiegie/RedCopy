### 详细说明

```
薯薯小抄是一款小红书笔记辅助工具，帮助创作者提取、分析与仿写笔记内容。

【主要功能】
• 一键提取笔记标题、正文、标签、图片与互动数据
• 复制 Markdown / 正文 / 图片链接
• 批量或单张下载笔记图片
• AI 分析笔记结构与传播逻辑
• 根据分析结果生成类似笔记，支持编辑与导出

【使用步骤】
1. 打开小红书笔记详情页
2. 点击扩展图标，在右侧侧栏操作
3. 执行提取 → AI 分析 → 生成类似笔记
4. 在侧栏右上角配置 DeepSeek API Key（AI 功能需要）

【说明】
• 当前版本完全免费
• AI 功能需用户自行申请 DeepSeek API Key，费用由用户承担
• Key 仅保存在用户本机，不上传至开发者服务器
• 视频笔记可提取文案，图片下载主要适用于图文笔记

【交流反馈】
QQ：1653444718
交流群：870774371
```

## 隐私权政策

商店必填「隐私权政策」URL。可将项目中的 `PRIVACY.md` 发布到：

- GitHub Pages
- Gitee Pages
- Notion 公开页

将公开链接填入商店对应字段。

**隐私权表单逐项怎么填？** 见 [隐私权填报指南.md](./隐私权填报指南.md)（含单一用途、数据类型、权限说明、审核回复模板，可直接复制）。

---

## 权限用途说明（审核用）

| 权限 / 域名 | 用途 |
|-------------|------|
| `sidePanel` | 在浏览器右侧显示操作侧栏 |
| `scripting` + `activeTab` | 用户点击「执行提取」时，读取当前笔记页内容 |
| `tabs` + `webNavigation` | 检测是否在小红书笔记详情页，控制按钮状态 |
| `downloads` | 用户主动下载笔记图片 |
| `storage` | 本地保存 API Key、上次提取/分析/生成结果 |
| `*.xiaohongshu.com` | 访问小红书笔记页面 |
| `*.xhscdn.com` | 下载笔记图片 CDN 资源 |
| `api.deepseek.com` | 用户自备 Key 调用 AI 分析/生成 |

**数据收集声明：** 本扩展不收集、不上传用户个人信息。所有笔记内容与 API Key 均保存在用户本机。
